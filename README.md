# AnatoMech — Multiplatform Systems Project

Static presentation website for an academic team in the Multiplatform Software Development program at **Fatec Registro**. It introduces the team and showcases **DeepBody**, an educational concept focused on anatomy visualization and augmented reality.

## What this repository contains

- `index.html`: AnatoMech institutional landing page, team information, and project overview.
- `deepbody.html`: DeepBody concept presentation, interface imagery, and proposed AR-related features.
- `style.css`: responsive visual styling.
- `images/`: project and team artwork.

## Technology stack

HTML5, CSS3, JavaScript/Bootstrap-based page interactions, Bootstrap 5, Bootstrap Icons, and Google Fonts. The HTML pages use CDN-hosted assets for some presentation dependencies.

## How to run

Download or clone the repository, then open `index.html` in a web browser. Navigate to `deepbody.html` for the project showcase.

```bash
git clone https://github.com/vftheodoro/Anatomech.git
cd Anatomech
```

Running a static local web server is optional but useful for testing asset paths. Internet access is needed for CDN-loaded styles and fonts.

## Scope and status

This repository documents the **website and project presentation**. ARCore, interactive 3D anatomy visualization, and other DeepBody capabilities are described as a concept in the presentation; the repository itself does not provide a deployable AR application or proof that all advertised features are implemented.
